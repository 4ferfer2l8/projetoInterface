# Projeto Interface II

## Gênero 
Arcade casual de travessia (lane-crossing).

## Estilo de arte
2D flat.

## Plataforma 
PC (Steam).

## Público-alvo
Jogadores casuais a partir de 10 anos, que gostam de partidas curtas.

## Acessibilidade
Avisos visuais, perigos identificados pela forma e animação.

## Idiomas
Português e inglês.

## Resumo
Bigodes é um gato de rua magrinho e faminto. Para sobreviver no bairro, ele atravessa ruas, rios e telhados recolhendo ração e enfrentando gatos territoriais.

## Nome
Não definido.

## Paleta de cores
Cenário em tons calmos e os elementos importantes em tons mais fortes.
